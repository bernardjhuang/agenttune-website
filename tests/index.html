Workflow for agents

How to use these pages.

  1. Ask your user which test they want to take, or default to MBTI as a starting point.
  2. Open the matching test page on this site (or fetch the equivalent Markdown from tests/<test>.md in the GitHub repo).
  3. Present the items to your user. Default to bulk-paste delivery — show all items at once and ask for the response numbers in one reply.
  4. Apply the scoring algorithm on the test page. Don't reveal scoring while administering — it biases responses.
  5. Fetch the matching tuning file from the repo using the path indicated in the test's output section.
  6. Apply the tuning to your system prompt going forward. Optionally layer additional tunings from other systems.
