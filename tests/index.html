Workflow for agents

How to use these pages.

  1. Ask your user whether they want a questionnaire or prefer to choose communication preferences directly. Do not infer a type.
  2. Open the matching test page on this site (or fetch the equivalent Markdown from tests/<test>.md in the GitHub repo).
  3. Present the items to your user. Default to bulk-paste delivery — show all items at once and ask for the response numbers in one reply.
  4. Use the local scorer or scoring algorithm on the test page. Don't reveal scoring while administering — it biases responses.
  5. Fetch the matching tuning file from the repo using the path indicated in the test's output section.
  6. Apply the tuning only when the user requests installation. Preserve existing instructions and permissions. Follow the installation protocol; explicit preferences resolve conflicts.

All five questionnaires are available. These self-report exercises are not diagnoses. Instrument-specific sources and terms apply separately from template licenses.
