How to use the how to work with me card

  1. Write the preferences you want a teammate or assistant to know. You can use “me” instead of a name.
  2. Build the card and edit the output. Download Markdown or copy the text.
  3. If you want a share link, explicitly confirm that its contents are okay to share. The card is encoded in the link; anyone with the link can read it, and there is no server-side revoke button.

A concrete example

“Give me the recommendation first. When you disagree, point to the assumption you would change. For decisions, show the two most important tradeoffs.”

Questions and limits

What does a share link contain?

Only the current card output, up to 2,400 characters. It is encoded in the URL fragment, not stored in an AgentTune account. A link can still be copied, saved in browser history or exposed when shared. Never include secrets.

Can I change or revoke a shared card?

You can create a new link after editing. Older links still contain the older text, so there is no central revocation. For sensitive information, share a file through a channel you control instead.

Does the card define my personality?

No. It records preferences you choose to share, which can change by task or over time. Treat it as a conversation starter rather than a fixed label.
