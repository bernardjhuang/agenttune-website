How it works.

Each of the 43 tuning files is a ~200-word Markdown block describing how one personality type prefers to communicate — pacing, directness, decision framing, feedback style. This tool wraps that file in the right container for your agent: ChatGPT's "How would you like ChatGPT to respond?" field caps at 1,500 characters, so the generator checks the fit; coding agents read Markdown files like CLAUDE.md or AGENTS.md, so it emits an appendable section instead.

For the full experience — the tuning explained in plain English, how to talk to your type, install snippets for 13 agents — open your type's library page. For the method behind it, start with how to give your AI a personality.
