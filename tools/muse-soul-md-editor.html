How to use Muse Soul.md editor

  1. Paste or import your current Soul.md (or leave it blank to start fresh).
  2. Write your new communication rules or load the starter template, then click Preview merge.
  3. Download a backup of your original file, copy the merged Soul.md into Muse’s Assistant Identity settings, and test a few chats.

A concrete example

Your existing “Writing style” section stays intact while your new rules are placed inside visible agenttune:preferences markers.

Questions and limits

Does this tool update Muse automatically?

No. You copy or download the merged text and save it in Muse yourself.

What happens when I edit the file again?

If your file already has one complete agenttune:preferences block, the editor updates only that block and leaves everything else untouched. If markers are duplicated or incomplete, it stops so nothing is lost.

Should I put personal facts in Soul.md?

No. Keep tone and behavior rules in Soul.md, personal facts in Memory.md, and name/avatar details in Identity.md.
