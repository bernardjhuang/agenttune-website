How to use the muse soul.md editor

  1. Paste or import your current Soul.md. Leave it blank only when starting a new file.
  2. Write your preferences or load the starter. Preview the merge; text outside the labeled AgentTune block is preserved.
  3. Download the original backup and edited file. Review in Muse’s Assistant Identity settings, save manually, then compare responses. Undo here restores the local preview only.

Questions and limits

Does this tool update Muse automatically?

No. It produces a local text preview and download. You decide what to save in Muse. It cannot inspect your account or confirm that a preference persisted.

What happens when I edit the file again?

If the existing file contains one complete AgentTune preferences block, the tool replaces that block. Otherwise it appends a new block. Duplicated or incomplete markers are rejected so the tool does not guess what to remove.

Should I put personal facts in Soul.md?

Meta separates communication style in Soul.md from personal facts in Memory.md and identity in Identity.md. Use the relevant file for the information you want to change.
