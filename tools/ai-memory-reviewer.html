How to use the ai memory export reviewer

  1. Paste or import a memory-only text, Markdown, or JSON file. ZIP archives and full conversation-history migrations are not supported.
  2. Inspect the extracted entries. Categories are keyword hints. Uncheck anything you do not want to retain, edit the wording, and review any suggested redactions.
  3. Prepare the selected entries, read the final output, then download. Import manually using the destination’s supported controls. Your original account and files are not changed.

“I prefer short paragraphs” is labeled as a communication preference. An email address is flagged for review. Exact duplicate entries can be unchecked without deleting the original input.

Questions and limits

Is my memory export uploaded?

The tool parses and edits it in this browser tab. It does not send the content to AgentTune or a model. The page loads normal site assets; optional site analytics do not receive the contents of these fields. Clear the tool or close the tab when done.

Can redaction find every private detail?

No. The optional redactor handles email addresses, some common key formats, and long number patterns. It can miss names, addresses, health information and unfamiliar secrets, and may remove harmless numbers. Review every entry and the final output yourself.

Does JSON import preserve an export’s original structure?

No. It flattens primitive values into editable entries labeled with their original paths. It is a review aid, not a lossless vendor-format converter. Keep your original export and use a memory-only subset of at most 500 entries.
