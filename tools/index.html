Eight free tools · No signup

Make your AI easier to work with.

Write better instructions, keep the preferences that fit, and test what actually changes. Small, practical tools for your next conversation.

All eight tools process your input in your browser. No API key, model credits, or account required.

01 / Write and refine

Communication preferences builder →

Create instructions without taking a personality test.

Build custom AI instructions from your preferred tone, detail, feedback and format. No personality test or signup. Edit and export locally.

02 / Write and refine

Instruction checker →

Find duplicate rules and wording worth revising.

Check custom instructions for duplicate lines, absolute rules and possible conflicts. Review specific suggestions and choose which duplicates to remove.

03 / Write and refine

Muse Soul.md editor →

Safely add communication preferences to Muse Soul.md.

Edit Muse Soul.md with a merge preview, original-file backup and undo. Preserve existing preferences and add an editable communication template.

04 / Write and refine

Instruction converter & merger →

Format and merge your own text for a new destination.

Format your own instructions for ChatGPT, Claude, Muse, CLAUDE.md, AGENTS.md or an API. Preview merges without replacing existing project context.

05 / Test and compare

Instruction test bench →

Compare real answers before and after an instruction change.

Compare AI answers before and after changing instructions. Use fixed probes, randomized A/B labels, word counts and your own ratings. Export results.

Test a nine-group scoring interface using synthetic inputs. No personality questionnaire is included.

08 / Write and refine

How to work with me card →

Create an editable how-to-work-with-me card for teammates or AI assistants. Choose what to share, export Markdown or create an optional share link.

Start with the job you need done

Starting from scratch? Use the preferences builder. Already have instructions? Run the checker, then compare real responses in the test bench. A neat prompt is a starting point; actual usefulness depends on the model, task, and your judgment.

Explore more instruction tools

The original custom instructions generator and CLAUDE.md generator are still available, alongside the 43-file tuning library.

Use the tools with an agent or your own app

Read the machine-readable catalog and local JavaScript API documentation. The MCP endpoint at https://agent-tune.com/mcp exposes the catalog through get_free_tools; processing functions can be downloaded and run locally. Connecting an agent never installs instructions automatically.

Free means you can use the whole tool

There is no account wall or paid export. The test bench uses answers you provide, so any costs or limits in the AI service where you run a prompt still apply. Tool inputs are not uploaded or stored by AgentTune. Downloads and optional card links contain only what you explicitly choose to export or share.
