How to use the nine-group scoring demo

  1. Choose 36 demo values, import an array or load the neutral software fixture.
  2. Inspect the nine group totals and any ties. These are software test outputs, not personality results.
  3. Download the original React starter. Establish rights and versioning separately before adding a real instrument.

A concrete example

Thirty-six values of 3 produce nine totals of 12 and a nine-way tie.

Questions and limits

Does this include OEPS questions?

No. The controls are original synthetic placeholders for software testing. The former questionnaire is unavailable pending rights clarification.

How does the demo work?

Add four values per group. All highest totals are preserved; no forced winner or wing is inferred.

Can I reuse the code?

The original arithmetic and synthetic example are MIT. Obtain applicable permissions before adding a real questionnaire.
