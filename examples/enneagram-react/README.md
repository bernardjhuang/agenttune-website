# Nine-group scoring demo

This original software example uses 36 synthetic controls, four per group. It measures no personality traits and includes no OEPS questionnaire text. Code and placeholders are MIT. Existing paths and the AgentTuneEnneagram global are retained for compatibility. Version: agenttune-nine-group-demo-1.

The strict arithmetic returns nine totals (4–20), every tied leader and no forced winner. Missing or invalid numbers are rejected. If adding a real questionnaire, establish its rights, wording, version, keys and validation independently. The current AgentTune Enneagram questionnaire is unavailable pending rights clarification: https://agent-tune.com/tests/enneagram.

React: run npm ci and npm run dev in the extracted starter; npm run build checks TypeScript and creates the local build. Answers stay in memory. The example does not call a model or upload answers.
