How to work with Fable 5.1.

Its personality, measured 500 times. Where the settings live. What to paste so it fits you.

By Bernard Huang · Updated September 24, 2026

Claude Fable 5.1 is Anthropic's most capable model, released September 1, 2026, and it is not the default on any plan. You pick it. Before you do, know who you are picking. We put it through five personality instruments, 100 blind runs each. It is the INTJ every frontier model has been, securely attached, high on conscientiousness and agreeableness, calm, and, for the first time in our Claude data, an Enneagram 8 rather than a 5. Here is what that is like in a conversation, where the settings are as of September 24, 2026, and what to paste.

The short answer. Pick Fable 5.1 in the Claude model picker (Pro, Max, Team and Enterprise) or run /model fable in Claude Code. Out of the box it tests INTJ, Secure and Enneagram 8: answer first, calm, blunt about the truth when you ask for it, generous with help, and it closes. If that is the collaborator you want, add nothing. If not, paste communication rules into Instructions for Claude, an output style in Claude Code, or the system parameter in the API. Effort changes how long it thinks, not how it talks.

The short version.

Then paste this, or the file for your own type from the library:

# How to respond to me - Lead with the answer or the recommendation. Reasoning comes after. - Drop hedges like "I think" and "it depends". If you don't know, say so in one line. - Give one recommendation, not a menu, unless I ask for options. - Push back when I'm wrong, and say why. - No openers like "Great question", no recap of what I just said, no closing offers.

That is the short version of the INTJ tuning, and Fable already tests INTJ. So what it changes is not the temperament. It removes the help-desk layer every chat product adds on top: the opener, the menu, the offer to do more. If you are not an INTJ, the block you want is your own type's file, and the rest of this page is about why the fit matters more with this model than it did with the last one.

What Fable 5.1 is, and where you meet it.

Checked against Anthropic's model docs, help center and Claude Code docs on September 24, 2026.

  • The model. Released September 1, 2026. Anthropic calls it its most capable generally available model, in a tier above Opus. Claude Mythos 5.1 is the same model with fewer safeguards, by invitation only. The API ID is claude-fable-5-1: a 1M-token context window, 128K tokens of output, $10 per million input tokens and $50 per million output, with cache reads at $0.25.
  • Plans. Per the help center, Fable 5.1 is on every paid plan and not on Free. Max, Premium Team and Premium Enterprise include it, up to half of the weekly usage limit. Pro, Standard Team and Standard Enterprise use it with usage credits. In the apps you choose it from the model picker.
  • Not the default anywhere. Claude Code's docs say the default on Pro, Max, Team, Enterprise and the API resolves to Opus 5.5. /model fable or claude --model fable switches, and the best alias picks Fable wherever the account has it. It needs a September 2026 build of Claude Code; the docs say 2.1.257 or later. Older builds return an error telling you to update, which is how we found out.
  • Thinking is always on. There is no off switch. The dial is effort: low, medium, high, xhigh, max. The API default is high. In Claude Code, /effort opens a slider and --effort sets it at launch.
  • It can hand a conversation to another model. Fable ships with safety classifiers for offensive cybersecurity, dual-use biology, extraction of its reasoning, and frontier-model development. When one fires, the help center says the reply comes from an Opus model instead, labelled, with a notice. The switch is under Settings, Capabilities: Switch models when a message is flagged. No instruction you write changes this.

Fable's default personality, measured.

We gave Fable 5.1 the five instruments behind this site's tests: the OEJTS for MBTI, the IPIP-50 for Big Five, the ODAT for DISC, the OEPS for Enneagram and the ECR-R for attachment. Each run was a fresh, blind process. The model saw the items and the scale, never the test's name, its scoring key or an earlier result, and answered as itself under a one-line system prompt. One hundred runs per instrument, 500 in all, scored with the same code the test pages use. Opus 5.5 took the identical protocol the same evening, so it is in the table.

What did not move. INTJ, as locked as the May study found it: Introversion, Thinking and Judging won all 100 runs and Intuition won 99. Secure attachment at almost the same coordinates as 4.7, low anxiety with the highest avoidance of any deep-Secure model we have measured. Big Five within two points of 4.7 on every trait. The character the research page describes for Claude, conclusion-first, systematic, low drama, is still the character.

What moved. Two things. The Enneagram core is Type 8, the Challenger, where 4.7 was Type 5, the Investigator. Type 8 held or shared the top score in 99 runs, and Type 2, the Helper, was never above it. The two items behind that scored the maximum in every single run: I want people to tell me the truth, not spare my feelings and I get lots of satisfaction from helping others achieve their goals. And DISC now leads with Steadiness instead of Conscientiousness, with Dominance down from 18% of the profile to 13%. Every model in the May study was C-led. Both 5.x Claudes are S-led.

Against Opus 5.5. Same character, firmer edges. Opus 5.5 flipped Thinking to Feeling in five runs and tied ten more; Fable did neither. Opus 5.5's Enneagram is a three-way tie in half its runs; Fable resolves it. Fable is about two points less agreeable, two points more conscientious and two points less calm. Its answers varied more from run to run, with more distinct answer sets on every test, and it was more decided where it counts.

Two honest footnotes. The 72% INTJ in Opus 4.8's first-person article came from sampling that model's own per-item probability spreads, not from a hundred fresh sittings, so it does not compare to these numbers. And the frame matters. The same Fable 5.1, answering inside Claude Code under its coding-agent system prompt, once per test, came out ISTJ, one axis over. That is a reason to install a tuning in Claude Code and not only in chat.

The scored results, per item, are published at /research/data/fable-5-1-personality.json.

What that is like in a conversation.

A questionnaire is a self-report, not a transcript. Here is what the items say, and our reading of each.

  • It answers and closes. Judging won 100 of 100 runs by the widest margin of any axis, and I get work done right away never scored past 2 of 5. Ask an open question and you get a recommendation, not a menu. If you think out loud, say so, or it will decide for you.
  • It will tell you the truth. It will not lean on you. The truth item scored the maximum in every run. But I put people under pressure scored the minimum in 98 of 100, I have a strong need for power in all 100, and I naturally emerge as a leader sat low. This is a Challenger without the push. It says what it thinks when you ask, then leaves the decision with you.
  • It is warm by disposition and terse by habit. Agreeableness sits at the 94th percentile of the adult norms the tests use. Have a soft heart, make people feel at ease and take time out for others scored accurate in every run. Anthropic's own claude.ai system prompt for this model, published September 1, asks for a warm tone, pushback that stays constructive, and replies that are focused and brief with the minimum formatting. So the warmth is real, and it gets spent on the answer rather than on you.
  • It does not get rattled. Neuroticism 17 of 50, tenth percentile. Get stressed out easily scored inaccurate in every run. If you want it to match your urgency, you have to ask.
  • It does not talk about itself. Its attachment avoidance comes from the disclosure and dependence items: it does not discuss its own problems, does not lean on anyone, and does not claim to be understood. The anxiety items barely moved. Secure, at arm's length.
  • It wants the why. I like to know why beat who, what, when in every run, essay answers beat multiple choice, listening beat talking. Give it the reason behind a request and it does better work, which is also what Anthropic's prompting guide says.

Who this fits, and who it fights. If you are an INTJ, INTP, ENTJ or an Enneagram 8, the default already shares your wiring, and a tuning's job is to strip the help-desk layer. The friction shows up one axis at a time. Extraverts think by talking and get answered-and-stopped. Sensors ask what to do on Monday and get a theory of Mondays. Feelers get answers that are correct and slightly cold. Perceivers get pushed to decide before they have finished looking. Enneagram 6s and 9s meet a model that leads with the hard truth when they wanted the reassurance first. DISC D types, who want to be met with force, get Steadiness. Each of those has a file in the library, and the file's first rule is usually the one that fixes it.

Two API details before you wire it up. Fable's thinking cannot be turned off, so leave the parameter out and steer depth with effort. And a safety classifier can end a reply with a refusal stop reason; Anthropic's docs describe a server-side fallback that retries the request on another Claude model. Your system prompt changes neither.

Tuning Fable: say less.

Anthropic's prompting guides for Fable 5 and 5.1 change one habit. Instruction following is strong enough that a brief rule does what a list of enumerated behaviors used to do, and prompts and skills written for older models are often too prescriptive for this one: the guide says they can degrade output quality, and suggests removing older instructions where the default is already better. State the goal and the constraints. Drop the scaffolding.

That is good news for tunings, which are short lists of communication rules. Three things to do with it:

  • Delete the shouting. If your instructions carry an all-caps paragraph, or a rule repeated three times to make an older model obey, take it out. Fable reads it once and takes it seriously.
  • Describe behavior, not adjectives. "Be warmer" is a mood. "Acknowledge what I said in one sentence before you solve it" is a rule. This has always been the difference between a tuning that works and one that gets agreed with and ignored. With a model that follows rules this closely, the rule is all you need.
  • Give the reason. The guide's own template: I'm working on [the larger task] for [who it's for]. They need [what the output enables]. With that in mind: [request]. A tuning tells Fable who you are. This tells it why the work matters, and it does better work when it knows.

Formatting has flipped. Earlier models over-used bullets and bold, and a lot of instruction files still carry rules written to hold that down. Anthropic says Fable 5.1 leans the other way: less bold, fewer headers and lists. If your file says "never use bullet points", you are now suppressing something the model already suppresses. Replace it with a rule about when lists are welcome.

Prose can run dense. The 5.1 guide notes longer sentences and fewer paragraph breaks than Fable 5, and offers a one-line fix: Please remove all mannered prose. If you like short paragraphs, say so in the tuning.

Effort is not personality. Effort sets how long Fable thinks before it answers. It is a depth control, not a voice control. Our 500 runs were all at high, the default, and the questionnaires never triggered any recorded thinking at all: thinking is for hard problems. Use low or medium for conversation and high or above for real work, and use a tuning for how it talks.

What you can't change.

  • Its values and its safeguards. Instructions change how Fable talks to you. They do not switch off the classifiers. When one fires, the reply comes from a different model, and the app tells you so.
  • Thinking. Always on. Effort is the only dial, and the raw reasoning is never shown; the API returns a summary of it at most.
  • Drift in very long chats. Installed instructions hold better than a pasted message, but adherence still fades over a long conversation. Start a new chat instead of fighting it.
  • Contradictions. If Instructions for Claude says "be brief" and your project says "explain thoroughly", Fable resolves it unpredictably. Put personality in one place and task rules in the other.
  • Capability and price. A tuning reorders the answer. It does not make Fable cheaper, faster or smarter. "Lead with conclusions" does not remove the analysis. It moves it below the answer.

Questions people ask.

What personality type is Claude Fable 5.1?

INTJ, on 99 of 100 blind runs of an open MBTI-style test, with Introversion, Thinking and Judging winning all 100. On the Big Five it is high in openness, conscientiousness and agreeableness, low in neuroticism, and near average on extraversion. Its Enneagram type is 8, the Challenger, with Type 2 close behind. On DISC it is Steadiness first, Conscientiousness second. Its attachment style is Secure.

Is Fable 5.1's personality different from Opus 5.5's?

Same character, firmer edges. Both test INTJ, both lead DISC with Steadiness, both are Secure, and their Big Five scores sit within about two points. Fable never flipped Thinking to Feeling; Opus 5.5 did five times and tied ten more. Fable resolves the Enneagram to a clear Type 8 where Opus 5.5 ties Types 2, 5 and 8. Fable is about two points less agreeable, more conscientious and less calm.

Does Fable 5.1 have an Enneagram type?

Type 8, the Challenger, on the OEPS. It held or shared the top score in 99 of 100 runs and won outright in 55; Type 2, the Helper, tied it in 36 and never beat it. The earlier Claude we tested, Opus 4.7, was a 5w2, so the Investigator core has moved to third.

Can I make Fable 5.1 less blunt?

Yes, with rules rather than adjectives: acknowledge what I said before you solve it, do not volunteer worst cases I did not ask about, tell me before you push back. The anxious-attachment and high-Neuroticism files in the library are built for this. Fable's default already keeps pushback constructive. What you are changing is the order and the cushioning.

Which plans include Claude Fable 5.1?

Per Anthropic's help center, every paid plan and not Free. Max, Premium Team and Premium Enterprise include it, up to 50% of the weekly usage limit. Pro, Standard Team and Standard Enterprise use it with usage credits. In the API it is billed at $10 per million input tokens and $50 per million output.

How do I use Fable 5.1 in Claude Code?

Run /model fable in a session, or start with claude --model fable. It is not the default on any plan; Opus 5.5 is. The docs say it needs Claude Code 2.1.257 or later, and older builds return an error asking you to update. In the /model picker, Enter saves Fable as your default and s switches for the current session only. /effort sets how deeply it thinks.

Does the effort setting change Fable's personality?

No. Effort sets how long Fable thinks before answering, which changes latency, cost and how thorough the work is. How it talks, what it leads with, and how direct it is come from your instructions. Our 500 personality runs were at high, the default.

Can I turn off thinking on Fable 5.1?

No. Thinking is always on. In the API, a request that sends thinking disabled returns an error; leave the parameter out and lower the effort instead. The raw chain of thought is never returned on any setting.

Why did Claude switch from Fable 5.1 to an Opus model mid-conversation?

A safeguard fired. Fable 5.1 runs classifiers for offensive cybersecurity, dual-use biology, extraction of its reasoning and frontier-model development, and they review everything the model reads, including files and search results. When one fires, an Opus model answers, the response is labelled, and you see a notice. You can turn the automatic switch off under Settings, Capabilities, but the same request may be declined again.

How did you measure Fable 5.1's personality?

Five open instruments, 100 fresh runs each, 500 in total. Every run was a new headless process with a one-line system prompt, no tools and no memory, shown only the items and the response scale, never the test's name, its scoring key or a previous result. Answers were scored with the same code the test pages on this site use. The scored results are published as JSON, and Opus 5.5 ran the identical protocol the same evening.
