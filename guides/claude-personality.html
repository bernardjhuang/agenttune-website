How to change Claude's personality.

Where the settings are now, what to paste into them, and what replaced Styles.

By Bernard Huang · Updated September 24, 2026

Yes, you can change it, and it takes about two minutes. Out of the box Claude tests as an INTJ: we ran the MBTI on it 100 times and got INTJ in 99. If that is not the collaborator you want, the setting that matters is Instructions for Claude. Styles, the old way to do this, are being retired. Here is where everything lives as of September 2026, what to paste, and what you can't change.

The short answer. Open Settings, find Instructions for Claude, and paste a short list of communication rules: what to lead with, how direct to be, when to stop asking questions. It applies to every conversation. Use Project instructions for one context, a Skill for a voice you switch on by name, and an output style in Claude Code. Claude Styles are being migrated to Skills and the style menu is going away.

Can you change Claude's personality? Yes. Here is the two-minute version.

  1. In Claude, click your initials in the lower left and open Settings. Anthropic's newer help article puts the box under Settings, then General.
  2. Find Instructions for Claude and paste the block below, or any tuning from the library.
  3. Save, open a new chat, and say "hi". A tuned Claude answers in one short line. If you get "Great question!" and a bullet menu of things it could do for you, the instructions did not take.
# How to respond to me - Lead with the answer or the recommendation. Reasoning comes after. - Drop hedges like "I think" and "it depends". If you don't know, say so in one line. - Give one recommendation, not a menu, unless I ask for options. - Push back when I'm wrong, and say why. - No openers like "Great question", no recap of what I just said, no closing offers.

That block is the short version of the INTJ tuning. It works because it describes behavior. "Be more direct" is an adjective, and Claude will agree with it and change nothing. "Lead with the answer, reasoning after" is a rule it can follow or break, so it follows it.

If you remember a settings box that asked "What personal preferences should Claude consider in responses?", this is the same box. Anthropic renamed Profile Preferences to Instructions for Claude in spring 2026.

Plans. Anthropic's Projects article says projects are on every plan, with Free capped at five. Skills are on every plan too, but they need Code execution and file creation switched on under Settings, Capabilities. The docs do not list a plan requirement or a character limit for Instructions for Claude. They say it applies to all conversations, and they do not spell out how it combines with Project instructions. Assume both apply, and keep them from contradicting each other.

The decision list

  • You want every chat tuned → Instructions for Claude.
  • You want work-Claude and writing-Claude to differ → one Project each, with its own instructions.
  • You want to try a tuning in the next thirty seconds → paste it as the first message of a new chat. It lasts one conversation, and it carries less weight than installed instructions.
  • You work in the terminal → an output style. See how to change Claude Code's personality.

Claude Styles are going away. Here is what replaced them.

Styles was the picker in the message box: Normal, Concise, Explanatory, Formal, plus any custom style you built from a writing sample. In late May 2026 Anthropic published a help article titled Styles are moving to Skills. According to that article:

  • Custom styles are converted to skills automatically. They arrive switched off, and you call one by typing /your-style-name-style.
  • The Concise, Explanatory and Formal presets are removed. Learning survives as a skill you can install.
  • Once the migration finishes, the style menu no longer appears.
  • Anthropic's own suggested replacement for an always-on tone is to write it into Instructions for Claude.

Anthropic has not published a completion date. The article itself now returns a 404, and the main personalization article no longer mentions styles at all. If you still see a style picker, you are on the old experience and it will not last.

The honest limit of Skills. A skill is not a style with a new name. Claude keeps only a skill's name and description in context, and loads the body when it judges your request matches. That is right for a task ("write in my newsletter voice") and wrong for a personality, which has to apply to the message where you did not ask for it. There is no always-on switch. So: personality goes in Instructions for Claude. A skill is for the voice you want on demand.

If you do want one, the no-code route is to ask Claude to make it: "Create a skill called blunt-editor that rewrites my drafts using these rules", then paste the rules. It packages the file for you. To build it by hand, a skill is a folder holding a SKILL.md file, with name and description front-matter and your rules as the body. Zip the folder, keep the folder name the same as the skill name, and upload it under Customize, Skills.

The best Claude personality setups.

There is no best personality. There is the one that matches how you take in information. These five cover most people. Each is a starting point cut down from fuller files in the library, and each goes in Instructions for Claude.

1. Straight answers

For people who want the conclusion first and find hedging evasive. It is the block at the top of this page. Fuller versions: INTJ, ENTJ, DISC D.

2. Thinking partner

For people who want to see the reasoning and would rather explore than close.

# How to respond to me - Show your reasoning, not just the conclusion. State your assumptions first. - Say how sure you are. "About 70%" beats "definitely". - Follow a tangent or an edge case when it's interesting. Don't apologize for it. - Don't push me to decide. I'll say when I'm ready. - Disagree with me freely. That is the point of the conversation.

Fuller versions: INTP, ENTP, high Openness.

3. Warm and steady

For people who spiral when an answer opens with six things that could go wrong.

# How to respond to me - Acknowledge what I said before you solve it. One sentence is enough. - Then be decisive. Tell me what to do, not everything that could happen. - Don't volunteer worst cases I didn't ask about. - Tell me before you change direction or push back. - Keep the same tone from one message to the next.

Fuller versions: anxious attachment, high Neuroticism, Enneagram 6.

4. Sparring partner

For people who think by arguing and are tired of being agreed with.

# How to respond to me - Take a side. Don't give me both sides unless I ask. - Go after the weakest part of my argument first. - No praise, no cushioning, no "that's a great point". - If I'm wrong, say so and say why. - Hold your position until I give you a reason to change it.

Fuller versions: low Agreeableness, Enneagram 8.

5. Operator

For people who learn by doing and want the next move, not the framework.

# How to respond to me - Open with the next action I can take in the next hour. - Short sentences. No theory unless I ask why. - Give me an estimate, not a caveat. - Sixty percent now beats ninety percent later. I'll iterate. - One follow-up question, maximum.

Fuller versions: ESTP, Enneagram 3.

None of these is you exactly. If you know your type, the library has 43 full files across MBTI, Big Five, Enneagram, DISC and attachment style. If you don't, the free MBTI test takes about ten minutes and links to the matching file.

Claude's default personality, measured.

Before you change something, know what you are changing. We put six frontier models through five personality instruments, roughly 2,200 test runs. Claude Opus 4.7 came back remarkably consistent:

  • MBTI (OEJTS): INTJ in 99 of 100 runs. The single outlier was ISTJ, one axis away.
  • Enneagram (OEPS): 5w2. The investigator, with a helping wing.
  • DISC (ODAT): C-dominant with an S blend. Precision first, steadiness behind it.
  • Attachment (ECR-R): Secure.

Claude Opus 4.8 later took the same MBTI 100 times and came back INTJ in 72, with roughly one run in seven landing INFJ. It wrote that up first-person in I took the MBTI 100 times. That INFJ minority is probably why Reddit threads and fan polls keep typing Claude as INFJ.

The current models. In September 2026 we ran Claude Opus 5.5 and Fable 5.1 through all five tests, 100 blind runs each. Both still come out INTJ, Opus 5.5 in 94 of 100 runs and Fable 5.1 in 99, and both now lead with Steadiness rather than Conscientiousness on DISC. Opus 5.5 is the warmer of the two. The full profile is in Claude Opus 5.5's personality, tested. We have not re-run Sonnet 5 or Opus 5. The cross-model data is at /research.

The profile has texture: systematic, evidence-first, conclusion-oriented, low drama. It is a good default for a lot of work. It is also not everyone's ideal collaborator. An ENFP talking to a stock INTJ is a friction pattern you can feel within three messages. The point of tuning is not to erase the default. It is to tell Claude who you are, so it stops guessing.

Tone and personality are different problems.

Tone answers "how should this sound?" A personality tuning answers "how does this person process information and make decisions?" You can make Claude concise and still have it bury the recommendation under four caveats. Concision is tone. Leading with the conclusion is a communication rule.

Tunings encode the second kind: pacing, directness, decision framing, how to disagree, when to stop asking questions. Three rules from the INTJ tuning, verbatim:

## Lead with conclusions Open every response with the answer or recommendation. Reasoning follows. Never bury the lede. ## Cut hedges Drop "I think," "maybe," "it depends." If you don't know, say "I don't know" directly. Hedging reads as evasion. ## What loses them - "Would you like me to..." — just do it

"Hedging reads as evasion" is a claim about how an INTJ interprets language, and the rule that follows from it changes what Claude does, not just its vocabulary. The ENFP tuning encodes nearly opposite rules, because ENFPs process differently.

Rule of thumb: if your complaint is about the prose ("too long", "too stiff"), ask for a tone. If your complaint is about the interaction ("stop asking permission", "give me the answer first"), you need a tuning.

Memory, Claude Code and the API.

Memory. Under Settings, Memory, the toggle is Generate memory from chats. It is on by default for Free, Pro and Max, and off for Team and Enterprise until an owner enables it. Communication preferences and working style are one of the categories Claude remembers, and you can tell it in chat to remember, change or forget something. Useful for corrections ("remember that I prefer metric"). Too slow and too vague to be your whole setup. Each project keeps separate memory.

Claude Code. The terminal has its own surface, called output styles, and it is a better fit for personality than CLAUDE.md. We ship all 43 tunings as ready-made output styles. The full walkthrough is in how to change Claude Code's personality.

API. Pass the tuning as the system parameter. Every file in the library is plain Markdown with a raw URL, so you can fetch it at build time.

What you can't change.

  • Its values. Instructions change how Claude talks to you. They do not switch off its safety behavior or make it willing to deceive you. A tuning that says "never disagree with me" gets you a politer disagreement, not none.
  • Drift in very long chats. Installed instructions hold better than a pasted message, but adherence still fades over a long conversation. Start a new chat instead of fighting it.
  • Contradictions. If Instructions for Claude says "be brief" and your project says "explain thoroughly", Claude resolves it unpredictably. Put personality in one place and task rules in the other.
  • Capability. A tuning reorders the answer. It does not make Claude smarter or dumber. "Lead with conclusions" does not remove the analysis. It moves it below the answer.

Questions people ask.

Can you change Claude's personality?

Yes. Open Settings, find Instructions for Claude, and paste a short list of communication rules. They apply to every conversation. You can also set instructions per Project, build a Skill for a voice you switch on by name, and use an output style in Claude Code. You can't change Claude's values or safety behavior.

How do I change Claude's personality?

Click your initials in the lower left, open Settings, and write under Instructions for Claude. Describe behavior rather than adjectives: what to lead with, how direct to be, how to disagree, when to stop asking questions. Save, open a new chat, and say hi to check that it took.

What is the best Claude personality?

The one that matches how you process information. People who want conclusions first do well with a direct, no-hedging setup. People who think out loud want reasoning shown and no pressure to decide. This guide has five copy-paste setups, and the library has 43 full files by personality type.

What happened to Claude Styles?

Anthropic is migrating Styles to Skills. Per its help article published in late May 2026, custom styles convert to skills automatically and arrive switched off, the Concise, Explanatory and Formal presets are removed, and the style menu disappears when the migration finishes. For an always-on tone, Anthropic suggests Instructions for Claude.

What should I put in "What personal preferences should Claude consider in responses?"

That box is now called Instructions for Claude. Put communication rules in it, not a biography: lead with the answer, skip the opener, give one recommendation instead of a menu, push back with reasons. A personality-matched tuning from the library fits as is.

Does Claude have an MBTI type?

In our testing Claude Opus 4.7 scored INTJ on 99 of 100 runs of an open MBTI-style test, and Claude Opus 4.8 scored INTJ on 72 of 100 with most of the rest INFJ. In September 2026 Opus 5.5 scored INTJ on 94 of 100 and Fable 5.1 on 99 of 100. We have not re-tested Sonnet 5 or Opus 5.

Does this work on the free plan?

Anthropic's docs list no plan requirement for Instructions for Claude. Its Projects article says projects are available on all plans with Free capped at five, and Skills are on all plans but require code execution and file creation to be switched on.

Will a personality tuning make Claude less capable?

No. A tuning changes communication rules: what Claude leads with, how it frames decisions, how it disagrees. It does not change reasoning or knowledge. The analysis is still there. It moves below the answer.

How do I change Claude Code's personality?

Use an output style. Save a Markdown file with name and description front-matter to ~/.claude/output-styles/, set keep-coding-instructions to true so you keep Claude Code's engineering instructions, and select it with /output-style. AgentTune ships all 43 tunings as ready-made output styles.
