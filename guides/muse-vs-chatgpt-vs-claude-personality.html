Muse vs ChatGPT vs Claude: where the personality lives.

Three assistants, three homes for the same rules. Checked against each vendor's help center on September 25, 2026.

By Bernard Huang · Updated September 25, 2026

The same twelve lines of communication rules work in all three. Where you put them, whether you can read them back, and what the assistant remembers on its own are different in each. Muse keeps its personality in a file you can open. ChatGPT gives you a text field and seven presets. Claude gives you an account-wide instructions box, per-project instructions and a memory that stores your communication preferences whether you wrote them down or not.

The short answer. Muse: paste rules into Soul.md (Assistant icon, then Identity, then Soul) or ask in chat; no published limit; a Memory.md file you can edit. ChatGPT: Settings, then Personalization: custom instructions (1,500 characters on Free and Go, 5,000 on paid plans) plus a Base style and tone preset (Default, Professional, Friendly, Candid, Quirky, Efficient, Cynical); saved memories can override a preset. Claude: Instructions for Claude under Settings, project instructions per project, Skills on demand; memory is on by default for Free, Pro and Max, saved as individual topics you can edit under Settings, then Memory.

The same twelve lines, three places.

One block, written as rules the model can check itself against rather than adjectives:

## How to talk to me - Lead with the answer or the recommendation. Reasoning after. - Say what you don't know in one line. Don't hedge around it. - Give one recommendation, not a menu, unless I ask for options. - Push back when I'm wrong, and say why. - No openers, no recap of what I said, no closing offers.
  • Muse: Assistant icon, then Identity, then Soul. Paste at the end of Soul.md under its own heading and keep everything above it. Or say "Add these rules to your Soul file under a heading called How to talk to me. Don't change anything else. Then show me what you added."
  • ChatGPT: Settings, then Personalization, then the custom instructions field. Keep it under 1,500 characters on Free and Go. Pick the Efficient or Candid preset if you want the built-in style to pull the same way.
  • Claude: Settings, then Instructions for Claude. Put a project-specific version in that project's instructions instead when the rules only apply there.

Then open a new conversation and say "hi". A tuned assistant answers in one short line. A paragraph with a menu of things it could do means the rules did not take.

Presets versus rules.

ChatGPT is the only one of the three with a personality picker, and OpenAI's own page is careful about what it does: a preset shapes style and tone, does not change what ChatGPT can do, and gives way to memories and instructions that conflict with it. It also does not govern content you ask for by type: with Friendly selected, a request for code returns plain code.

That is the difference between a preset and a rule. "Candid" is a grade someone gives afterward; "say what you don't know in one line" is something the model can check on every reply. Use the preset for the register and the instructions for the behavior. In a 60-reply test on Claude Opus 5.5, a rules block like the one above cut hedges from 0.35 to 0.05 per reply and questions asked back from 0.9 to 0.25 without changing length; the write-up has every reply.

Memory is where they really differ.

Muse treats memory as a file. You can read Memory.md, edit it, and Meta's help page tells you exactly where it is. The cost is that Muse also learns from patterns it observes and from connected apps, and the training toggle is on until you turn it off.

Claude's memory is the most explicit about storing communication preferences and working style, which means it can quietly hold a version of your personality that you never wrote down. Settings, then Memory shows the entries and lets you delete or rewrite them, and incognito chats keep a conversation out entirely.

ChatGPT's saved memories sit next to the preset and the instructions, and OpenAI says a memory can override a preset. If ChatGPT seems to ignore a personality you picked, the memory is the first place to look.

Which one fits how you work.

  • You want to see the whole configuration in one place: Muse. It is a Markdown file, and Meta lets you edit it.
  • You want a one-click style and a short instruction: ChatGPT. Seven presets, plus 1,500 characters that fit a compact tuning.
  • You run different work in different contexts: Claude. Account-wide instructions plus per-project instructions, and a memory you can pause.
  • You use more than one: keep one Markdown block and paste it into all three. The rules do not change; only the box does. The generator formats a library tuning for each destination.

What the models themselves are like.

Separately from where the settings live, the models answer personality questionnaires differently. In September 2026 runs, Claude Opus 5.5 was the most agreeable model we have measured (47.1 of 50), GPT-6 Astra split ISTJ and INTJ almost evenly, and Muse Spark 1.3 was reported ISTJ in 80 of 100 runs, the first non-INTJ default in our data. The rankings and the per-model pages (ChatGPT, Claude, Muse) have the numbers and their limits.

Questions people ask.

Does ChatGPT have a personality setting?

Yes. Under Settings, then Personalization, the Base style and tone dropdown offers Default, Professional, Friendly, Candid, Quirky, Efficient and Cynical. OpenAI says a preset changes style only, applies across all chats, and can be overridden by a saved memory or an instruction.

Does Claude have personality presets?

No. Anthropic's personalization page lists Instructions for Claude (account-wide), project instructions and Skills. The older Styles picker is no longer listed. Claude's memory does store communication preferences it observes, which you can edit under Settings, then Memory.

Does Muse have custom instructions?

Not as a settings field. Muse keeps its personality in Soul.md, which you can open and edit under the Assistant icon, then Identity, then Soul, or change by asking in chat. Meta publishes no length limit.

Which assistant lets me see everything it remembers?

Muse and Claude both show you the entries: Muse as the Memory.md file, Claude under Settings, then Memory. ChatGPT lists saved memories in Settings. Muse also learns from observed patterns and connected apps, and Claude keeps a separate memory per project.

Can I move my memory between them?

Muse imports a .zip export from another assistant (Settings, then Data Controls, then Import memory). Claude imports pasted text (Settings, then Memory, then Start import) and calls it experimental. Export from Claude by asking it to write out its memories verbatim; ChatGPT includes custom instructions in its data export.

Can I use the same personality file in all three?

Yes. The rules are plain Markdown. Keep one block, paste it into Soul.md, the ChatGPT custom instructions field and Instructions for Claude, and shorten it under 1,500 characters for ChatGPT's Free and Go plans.
