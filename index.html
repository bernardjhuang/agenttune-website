Start with one clear request.

Telling an AI to “be more direct” is too vague. Instead, tell it where to start the answer, how much detail to include, and when to push back.

For example: ask it to lead with the recommendation, name the main trade-offs, and flag anything uncertain. Your live prompt in chat still overrides these defaults whenever you need something different.

Default reply Broad menu + preamble

That's completely normal! Everyone hits a wall sometimes. Here are a few approaches you might try: 1. Break the project into smaller, manageable steps 2. Take a short break and come back with fresh eyes 3. Talk it through with a colleague 4. Identify what specifically feels stuck Which of these resonates most? Happy to explore any of them!

With answer-first + structure rules Direct diagnosis

List the project's next three deliverables and mark which one has an unresolved input or decision. Being stuck is usually an unmapped dependency or an unmade trade-off rather than a lack of effort. Reply with the deliverable you are avoiding and what makes it ambiguous; we will isolate the blocker and pick one next action.
